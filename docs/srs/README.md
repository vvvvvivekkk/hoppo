# Source documents

- **`srs-v1.md`** — the Software Requirements Specification, IEEE 830 style.
  The baseline for design, implementation and acceptance testing. Requirement
  identifiers from this document (`FR-DLV-04`, `NFR-S-02`, `C-2`) are cited
  throughout the codebase.
- **`stack-and-screens.md`** — the technology stack decisions and the
  screen inventory (roughly 85 screens across three clients, phased P1/P2/P3).

Where the implementation departs from these documents, the departure is
recorded in [`../srs-resolutions.md`](../srs-resolutions.md) with reasoning.
Nothing was changed silently.
